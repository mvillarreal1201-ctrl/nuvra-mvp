# Moonframe

Anime-inspired static landing page for a fictional watch club.

## Files

- `index.html` - page structure and content
- `styles.css` - visual system, layout, and responsive styling
- `app.js` - character spotlight switching, form confirmation, and reveal animations

## Preview

Open `index.html` in a browser.

If you want a local server instead of opening the file directly, run one from this folder with a tool you already have installed, such as:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.
